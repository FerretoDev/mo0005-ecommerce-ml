# diagrama-er

Diagrama entidad-relación del modelo relacional de Olist (esquema `olist` de PostgreSQL). Refleja el esquema de [`datos/schema.sql`](../datos/schema.sql).

## Archivos

- `diagrama-er.drawio`: fuente editable (draw.io / diagrams.net).
- `diagrama-er.png`: imagen exportada que usa el informe (sección 2.9). Para regenerarla: abrir el `.drawio` en https://app.diagrams.net, Archivo, Exportar como PNG, zoom 200 %, fondo blanco, y guardarla aquí con el mismo nombre.
