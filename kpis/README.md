# kpis

Consultas y definiciones de los 11 KPI del proyecto.

- [`kpis.sql`](kpis.sql): consultas SQL de los 11 KPI (usan las vistas de [`datos/views.sql`](../datos/views.sql)).
- Las definiciones y fórmulas de cada KPI (población, cálculo y relevancia) se documentan aquí en archivos de texto o tablas.

Para ejecutar las consultas y guardar la salida en `datos/resultados_kpis.txt`: `./cargar.sh --kpis` desde la raíz del repo.
